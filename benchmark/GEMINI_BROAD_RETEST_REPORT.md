## 수정 사항

코어 0.17.5 / 결과 스키마 0.17 유지.

1. 최초 영역 식별에서 온전한 설명 문단과 주 작업물을 우선한다. 렌더 입력 3,000px, 비전 영역 추론 HIGH, 문단 주변 실제 여백 지시를 적용했다. 실패 박스를 자동 확대하거나 원문을 복구해 통과시키지는 않는다.
2. 정상 출처의 단일 주장만으로 `documented`가 되면 `needs_explanation`으로 보수적으로 낮추고 이유를 남긴다. 원본 모델 응답은 보존한다. 잘못된 ID·앵커·미확인 출처는 여전히 거부한다.
3. 조건부 본문 뒤에서 복사한 답변 과제에 조건이 누락되면 로컬 검사에서 제외한다. 전체 구성에 대한 과도한 단정과 같은 분위기·메시지 질문의 반복을 생성·검수 지시에서 명시했다.

무과금 코어 **154/154**, 타입 검사 통과. 원문·수량·지표·페이지·예산·재시도 검사 유지. 새 의존성·모델·에이전트 프레임워크 없음.

실제 실패 저장 응답도 오프라인으로 재생했다. 1차 마케팅의 `raw-018/020/022`를 그대로 사용해 읽힌 지표 하나만 `needs_explanation`으로 낮추고, 잘못 인용된 나머지 두 개는 계속 `unsupported`로 남기는 것을 확인했다. 추가 API 호출 0, 형식 재시도 0. 이는 해당 중단 원인의 회귀 검사이며 새 질문 품질 시험은 아니다.

## 2차: 수정 후 동일 두 PDF

실행 `gemini-broad-20260920-02`. 두 문서 모두 끝까지 완료했다. 각 실행 중 코드를 고정했다. 추가 유료 재분석 없이 보존된 결과와 원문을 대조했다.

| 문서 | 자동 최종 질문 | 별도 적합·비중복 | 결과 | 시간 | 실제 비용 |
|---|---:|---:|---|---:|---:|
| 디자인 | 7 | 6 | 콘셉트 설명 복구, AI 과정 누락·미확인 의도 전제 1개 | 598.610초 | $0.77312075 |
| 마케팅 | 9 | 8 | 지표 해석 질문 생성, 용어 1개 보류·핵심 2포인트 미충족 | 665.423초 | $0.97207535 |

디자인에서 원본 그대로 적합한 카드는 q1·q2·q4·q5·q6·q7이다. q3은 화면 관찰만 연결한 채 광고/제안이라는 선택지와 지원자가 보여주려 했던 의도를 묻는다. 화면의 용도나 지원자의 기획 참여를 먼저 열린 방식으로 확인해야 한다. 그림을 잘 인지했더라도 질문 카드의 전제를 같은 Gemini 검수가 놓칠 수 있음을 재확인했다.

질문 내용은 작은 장식 묘사에서 다음과 같은 작업 설명으로 이동했다. 이는 원본 자동 질문 예시이며 사람이 수정하지 않았다.

- “이 생일 카페 이벤트에서 빵집 콘셉트를 선택한 배경과, 그 콘셉트로 전하려 한 메시지를 설명해 주세요.”
- “지금 돌아볼 때 이 생일 카페 이벤트가 의도한 콘셉트를 잘 전달했는지는 어떤 기준으로 판단하시나요?”

5페이지 설명문의 실제 잘림은 해결됐다. 다만 24페이지는 온전한 본문 위쪽에 별도 제목의 일부가 걸려 잘림 검사에 탈락하는 **과잉 제외**가 남았다. 새 박스를 자동 확대하거나 이 실패 항목을 억지로 통과시키지 않았다. 컬러 근거 한 개의 수량·필드 원문 오류와 AI 프레임 한 개의 미확인 브랜드/영상 형식도 제외 기록에 남겼다.

자동 coverage는 일러스트와 색상 선정을 하나로 묶어 충족 처리했으나 실제 색상 질문은 없다. 별도 검수에서 이를 완전한 충족으로 인정하지 않았다. 디자인 선정 페이지는 두 번 모두 같지만 포인트는 3개에서 2개로 달라졌으며, **6/9 → 6/7을 동일 조건의 모델 정확도 상승으로 해석하지 않는다.**

디자인 2차 사용량: 호출 21, 입력 144,407 / 출력 39,268(추론 7,359 포함), HTTP 재시도 0, 형식 재시도 2, 적합 질문당 전체 분석 비용 $0.12885346. 고해상도·HIGH 추론과 재시도로 시간이 늘었으므로 속도까지 개선했다고 주장하지 않는다.

마케팅은 q5를 제외한 8개를 명확한 적합 문항으로 판단했다. q5는 원본의 **노출 아래 해시태그 항목**을 '해시태그 유입 지표'라고 부른다. 숫자 오류로 확정한 것은 아니지만 방문/트래픽으로 오해될 수 있어 보수적으로 보류했다. q2의 노출·도달은 자기 연결 크롭 안에 실제로 보여 질문은 적합하지만, 생성 입력의 인용과 검수 `premise_checks=[]`는 그 사실의 추적 기록을 충분히 남기지 못했다.

집행 기간·게시물 선정 설명은 잘린 첫 줄과 장식 경계에 반응한 보수적 검사로 빠졌다. 골프웨어 제안서는 독립적인 타깃·채널·블로그 내용을 하나의 근거에 묶었고, 그중 전사 오류와 비연속 인용 때문에 정상인 빅사이즈 추천 문장까지 함께 탈락했다. 두 실패 모두 기록했으며 자료를 바꾸거나 실패 문서를 성공 사례로 교체하지 않았다.

마케팅 2차 사용량: 호출 24, 입력 180,631 / 출력 52,333(추론 16,355 포함), HTTP 재시도 0, 형식 재시도 1, 적합 질문당 전체 분석 비용 $0.12150942. 두 번째에는 5·6·8·41페이지를 골랐으므로 첫 시험과 동일한 선정 조건의 성능 비교는 아니다.

**최소 MVP·10문항 목표 모두 미달이다.** 문서별 적합 질문 3개·실질 설명 2개 이상은 확보했지만, 모든 자동 최종 카드가 명확하게 적합하지 않고 선정 핵심 내용도 빠졌다. 단순히 질문이 더 넓어졌거나 실행이 완료됐다는 이유로 완성 처리하지 않는다. 현재는 검수 후 사용할 질문을 얻는 프로토타입 수준이다.

## 비용과 보존

기존 사용자가 승인한 USD23 창과 같은 원장을 재사용했다. 이번 재시험 전에 확인 지출 $3.08942750과 취소 요청의 미확인 노출 $1.67344를 유지했다. 후자는 전액 사용할 수 없는 유보로 남기며 실제 비용을 0으로 추정하지 않았다. 이전 $10/$15 원장을 변경하거나 새 승인 금액을 추가한 것이 아니다.

이번 요청에서 **두 PDF를 각 2회, 총 4회** 시험했다. 1차 $1.16578295 + 2차 $1.74519610 = **실제 확인 비용 $2.91097905**. 전체 호출 84회, 입력 564,648 / 출력 160,418(추론 32,712 포함), 형식 재시도 7회, 애플리케이션 HTTP 재시도 0회다. 각 단계의 형식 재시도는 1회 상한을 지켰다. 공급자 내부 재시도는 미확인이다.

승인 창의 종료 원장: 확인 누적 지출 $6.00040655, 미확인 과거 비용 유보 $1.67344, 현재 사용 가능한 잔여 $15.32615345, 활성 예약 0, 차단 false. 유료 프로세스는 종료됐고 추가 호출을 예약하지 않았다. 이 값은 계정 전체 청구 상한이나 과거 미확인 요청의 실제 비용 확정이 아니다.

결과·원본 응답·이벤트·정확한 크롭·별도 감사 기록은 Git 제외 경로 `output/benchmark/runs/gemini-broad-20260920-{01,02}/`에 보존한다. 원본 최종 카드를 고치거나 덮어쓰지 않았다. 무과금 코어 154/154, root/web 타입 검사, diff 검사 통과. 이번에는 브라우저·배포 빌드·답변 저장 E2E를 재실행하지 않았다. 커밋·푸시 없음.

## 남은 우선순위

1. **영역과 문자 판독:** 제목/본문 겹침, 장식 경계 오탐, 실제 글자 잘림을 분리해야 한다. 강한 비전 추론만으로는 해결되지 않았다. 실패 박스를 무조건 확대하는 방식은 채택하지 않았다.
2. **근거의 독립성:** 타깃·채널·메시지를 한 항목으로 묶어 한 글자 오류로 전체를 잃는 문제를 줄인다. 정상 근거를 제외한 사례도 실패로 측정한다.
3. **카드 검수:** 시각 자료만으로 본인의 과거 의도를 단정하는 질문, 지표의 상위 분류 누락, 빈 전제 연결 기록을 잡아야 한다. 세부 질문을 강요하거나 답변 자체가 PDF에 적혀 있어야 한다고 요구하는 방식으로 돌아가지는 않는다.

이전 0.17.1 결과(디자인 자동9/별도4, 마케팅 자동3/별도2)는 [이전 보고서](MVP_VALIDATION_REPORT.md) 그대로 남긴다. 이번 질문 범위와 추출 변경이 있으므로 고정 조건의 모델 우열 비교로 해석하지 않는다. 20개 문서 전체 성능으로 확대하지 않는다.
