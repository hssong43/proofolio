17개 모두 Codex가 별도 Poppler 원본 이미지와 대조했다. 질문에 연결된 페이지·근거 식별자 오류와 중복은 발견하지 않았으나, **불확실한 수행/과정 등 전제 문제 12개**가 남는다. 이는 실제 저자의 거짓이나 실제 수행 여부를 판정한 것이 아니라 **현재 연결한 근거만으로 질문의 단정을 지지할 수 없다는 뜻**이다. 박스 오류는 별도 4개이며 전체 식별 영역을 전수 검수한 수치가 아니다.

## v0.7.5 종료 시점 판정 (과거 기록)

PDF → 직군별 분석 → 연결 근거 → 질문 → 품질 상태/가이드/영역 미리보기의 코어·CLI 경로를 구현했다. 질문이 부족하거나 선택 포인트가 빠지면 `needs_review`, 질문이 없으면 `insufficient_evidence`로 반환한다. 자동 `evidence_ready`가 정확성 보증은 아니다.

**이번 회귀 검수는 마쳤지만 완성 품질 기준은 미달이다.** 최근 6개 자료의 최신 결과는 ready 2개·needs_review 4개, 자동 질문 15개 중 명확한 근거·비중복 13개다. 디자인은 1/3개, 마케팅은 2/3개에서 명확한 질문 3개 이상이다. 잘못된 페이지나 새 수치/역할/실험 전제는 이 질문들에서 발견하지 않았지만, 목록 기호 전사와 잘린 연속 인용 문제 2개를 성공으로 세지 않았다. 핵심 포인트 누락도 남아 있다.

이 수치는 **서로 다른 개발 버전의 최신 결과 묶음**이고, 동일 코드의 성공률이나 일반화 정확도가 아니다. 이미 이전 결과를 본 회귀 자료이며 새 holdout이 아니다. v0.5의 20개 고정 평가는 [기존 보고서](REPORT.md)에 따로 보존한다. 최신 코드의 20개 품질 기준 충족으로 확대 해석하지 않는다.

## v0.7.5 당시 비용·안전·재현성 (과거 기록)

모든 유료 호출은 기존 `output/benchmark/api-budget.jsonl` 하나를 공유한다. 시작 $4.919497950 대비 추가 10,000원, 보수적 예산 환산 2,000원/USD로 누적 $9.919497950 전에 신규 예약을 막는다. 실제 환율·세금·계정 전체 청구 상한이 아니다.

최종 누적 $7.416556200, MVP 시작 대비 추가 $2.497058250(예산 환산 약 4,994원), 미정산 0·차단 없음. 이번 09-17 재개에서 추가된 비용은 $1.591702500이다. 남은 추정 예약 여유 $2.502941750을 소진하기 위한 실행은 하지 않았다. 이전에 사용자가 승인한 미확인 상한 1건 $0.066908250은 실제 사용량과 구분해 보존하며 새 미확인 호출은 없었다.

문서별 분석 시간은 위 표처럼 약 1분 40초~4분 35초이며, 미리보기 저장 시간은 별도 열이다. 첫 검증 근거도 수십 초 이상 걸리므로 즉시 응답이나 ‘압도적인 속도’를 주장하지 않는다. 단계별 시간·입출력/추론/캐시 토큰·정리 실패는 각 원본 JSON과 run report에 남는다.

현 상태는 **원문을 함께 보는 검수 보조 코어**다. 핵심 주제를 빼먹지 않는 자동 면접 질문 엔진으로의 완성을 선언하지 않는다. 남은 과제는 프로젝트 경계/주제 선정 정확도, 단편적 인용의 가독성, 같은 근거에서 독립적인 질문을 충분히 추출하는 문제이며, 다음 변경도 별도 코드 고정과 원문 검수가 필요하다. UI·답변 평가·Supabase는 이번 범위에 추가하지 않았다.

최신 코드의 전체 20개 평가와 별도 반복 2개는 아직 하지 않았다. 이전 버전의 반복 결과는 새로운 코드의 재현성 근거가 아니다. 기능 설명과 명령은 [README](../README.md), 출처·이용 조건은 [SOURCES](SOURCES.md), 상세 중단/재개 이력은 [CHECKPOINT](../CHECKPOINT.md)에 있다.
